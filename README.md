# Inventsmart
A lightweight, fast, and user-friendly web-based inventory management system built using PHP, JavaScript, CSS, designed to help small businesses manage products, stock levels, and availability efficiently.

Features
🔐 Secure Login & User Authentication
📦 Product & Stock Management
🏷️ Add, Edit, Delete Items
🔍 Live Search & Filtering
📊 Real-Time Stock Overview
📁 Category & Item Type Management
📱 Responsive UI (mobile & desktop)
⚡ Fast, lightweight, no heavy dependencies

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
Version Control: Git & GitHub

📂 Database
The project includes the full database schema required to run the system.
File: database/inventsmart_db.sql
This file contains:
All tables used by the system
Relationships & structure
Sample data (if included during export)

👉 How to Import
Open phpMyAdmin
Create a new database (e.g. inventsmart_db)
Go to the Import tab
Upload inventsmart_db.sql
Click Go

Your system is now ready to run with the complete database.
